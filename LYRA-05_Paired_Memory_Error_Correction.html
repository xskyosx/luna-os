Memory operations

How the correction works

Each address stores (C,S). The pair carries a small checksum:

CHECK = (C + S) mod 4

For this demo, a disagreement between the pair and its stored checksum triggers FAULT. The repair routine restores the corrupted side from the verified partner when the evidence is unambiguous.

Memory map

Top trace = C. Bottom trace = S. A repair event is marked in the event log.

Lantern recovery rule

VERIFY → ISOLATE → COMPARE → RESTORE → VERIFY AGAIN.

The simulator never silently overwrites a conflicting pair.
