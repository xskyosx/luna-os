# LUNA OS — Facebook & Community Sharing Plan

Facebook is part of the LUNA OS community plan, alongside GitHub and the local operating system.

## Roles

- **GitHub** is the canonical home for source code, issue tracking, documentation, releases, and versioned artwork files.
- **Facebook** is for public-friendly project updates, artwork reveals, short demos, progress notes, and community discussion.
- **LUNA OS / Dream Forge** brings the software, Sister characters, experiments, and creative world together.

## Sharing checklist

- [ ] Upload the final artwork file to the GitHub repository under an organized artwork directory.
- [ ] Review the image and caption for spelling, privacy, and any personal information before posting.
- [ ] Link to the relevant GitHub documentation or release.
- [ ] Publish to the intended Facebook Page or account only after the account owner reviews and approves it.
- [ ] Keep a copy of the posted caption and public post URL in the project log.

## Privacy and account safety

This document is a plan and draft, not a post already published to Facebook. Never put phone numbers, home addresses, private transcripts, access tokens, or credentials into public posts or repository files. Do not assume a Facebook account or Page is connected until the owner explicitly verifies it.
